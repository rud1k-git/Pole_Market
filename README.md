Pole Market

Pole Market - веб-приложение для размещения и поиска сельскохозяйственных товаров и услуг. Пользователь может зарегистрироваться как покупатель или продавец, создать объявление и связаться с другой стороной через чат.

1. Основные возможности
Регистрация и вход в систему; добавление, редактирование и удаление объявлений; каталог товаров; профиль продавца; личные сообщения; отзывы; жалобы; обращения в поддержку; панель администратора.

2. Используемые средства
Серверная часть написана на Python с использованием Flask. Данные хранятся в Microsoft Access в файле agro.accdb. Для доступа к данным используется драйвер ODBC. Интерфейс построен на HTML и шаблонах Flask.

3. Структура базы данных
Users - учётные записи пользователей. Products — объявления. ChatRooms и Messages — диалоги и сообщения. Reviews — отзывы о сделках. Reports — жалобы на объявления. SupportTickets — обращения в поддержку.

4. Запуск
Установить Python, Flask, pyodbc и драйвер Microsoft Access. В папке проекта выполнить команду python app.py. После запуска открыть в браузере адрес http://127.0.0.1:5000.
